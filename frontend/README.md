# React + Vite Frontend

A modern React frontend for the Malaysian Kuih Recognition system.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

The app will run on `http://localhost:5174` (or 5173 depending on availability).

## Build

```bash
npm run build
```

## Important

- Make sure the Flask backend is running on `http://localhost:5000`
- The backend must have CORS enabled (already configured in app.py)

## Features

- Beautiful landing page with gradient animations
- Animated background with canvas-based effects
- Image upload with drag-and-drop
- Real-time CNN classification 
- Gemini AI integration
- Poster generation
- History tracking
